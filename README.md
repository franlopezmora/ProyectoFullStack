## Inicializar Base de Datos

Para que la app funcione correctamente, necesitás una base de datos SQLite con la tabla `STARBUCKS_DIRECTORY`.

Podés crearla ejecutando el script SQL que se encuentra en `scripts/init.sql` o descargando el archivo desde [aquí](URL).

> Alternativamente, podés pedírmelo si lo querés generado con datos de ejemplo 😉
